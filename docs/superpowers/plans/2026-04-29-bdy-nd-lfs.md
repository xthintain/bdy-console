# bdy nd + Built-in LFS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current real-Git-dependent LFS workflow with an independent `bdy nd` NetDisk version control system that includes project management, version history, Baidu Netdisk remotes, and built-in LFS.

**Architecture:** Add a new `.bdynd` repository model with content-addressed objects, refs, an index, and working-tree operations. Keep existing `cmd`, `home`, and legacy `sync` behavior intact while routing new project/version commands through `bdy nd`.

**Tech Stack:** Go standard library, existing Baidu API client, existing CLI dispatcher, JSON object storage, SHA-256 content IDs.

---

## File Structure

- Create `internal/bdynd/types.go`: shared object, ref, index, and config types.
- Create `internal/bdynd/repo.go`: repository discovery, initialization, path rules, and config persistence.
- Create `internal/bdynd/object.go`: content-addressed blob, tree, and commit storage.
- Create `internal/bdynd/index.go`: staging area operations.
- Create `internal/bdynd/status.go`: working-tree scan and index/head comparison.
- Create `internal/bdynd/commit.go`: commit creation, parent links, HEAD updates, and log traversal.
- Create `internal/bdynd/refs.go`: branches, tags, symbolic HEAD, and reflog.
- Create `internal/bdynd/diff.go`: text diff and summary diff.
- Create `internal/bdynd/worktree.go`: checkout, restore, reset, rm, and mv operations.
- Create `internal/bdynd/lfs.go`: internal LFS patterns, pointer files, cache objects, and checkout.
- Create `internal/bdynd/remote.go`: Baidu Netdisk remote layout, push/fetch/pull/clone.
- Create `internal/cli/nd.go`: `bdy nd ...` command parser and help.
- Modify `internal/cli/cli.go`: dispatch `nd` before legacy `sync`.
- Modify `README.md`: document `bdy nd` as canonical and mark old `sync/lfs` as legacy.
- Add tests under `internal/bdynd/*_test.go` and `internal/cli/nd_test.go`.
